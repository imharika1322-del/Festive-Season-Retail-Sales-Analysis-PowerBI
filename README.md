# Festive Season Retail Sales Analysis Dashboard | Power BI

## Project Overview
This project presents an interactive Power BI dashboard designed to analyze festive retail sales, customer behavior, product performance, and profitability.

## Project Objectives
- Analyze total sales and profit.
- Identify top-performing products.
- Understand customer purchasing behavior.
- Analyze state-wise sales.
- Compare payment methods.
- Evaluate sales channels.

## Dashboard Pages

### Page 1: Sales Overview
- Gross Sales
- Net Sales
- Estimated Profit
- Category-wise Sales
- Payment Method Analysis
- Geographical Sales

### Page 2: Product & Customer Analysis
- Product Performance
- Customer Type Analysis
- Category-wise Profit
- Store Format Analysis
- Customer Ratings
- Discount Analysis

### Page 3: Geographical Analysis
- State-wise Profit
- Category-wise State Performance
- City-wise Sales Channel Analysis
